# Contributing to Awesome Vibe Security

Thank you for helping grow the best curated list of **vibe security** resources!

## How to Add a Resource

1. **Fork** this repository
2. **Edit** `README.md` — add your resource to the most relevant section
3. **Submit** a pull request with a short description

## Format

```
- [Resource Name](https://url.com) — One sentence describing what it is and why it matters for vibe security.
```

## What We Accept

- Tools, scanners, and frameworks for securing AI-generated / vibe-coded applications
- Training, courses, and certifications for vibe penetration testing
- Research, blog posts, and articles specifically about vibe coding security
- CTF challenges or labs covering vibe security topics

## What We Don't Accept

- Generic security resources with no specific link to vibe coding or AI-generated code
- Unmaintained or broken links
- Duplicate entries already in the list
- Purely promotional content with no community value

## Quality Bar

Every resource should be:
- ✅ Directly relevant to **vibe security**, **vibe coding security**, or **vibe penetration testing**
- ✅ Actively maintained or evergreen content
- ✅ Genuinely useful — not just self-promotion
